# 🚀 Profile README Setup Guide for `@shubhmangalam19-collab`

Follow these quick 3 steps to activate your new GitHub profile:

---

### Step 1: Create Your Special Profile Repository on GitHub
1. Open your browser and go to: **[github.com/new](https://github.com/new)**
2. In the **Repository name** field, type exactly:
   ```text
   shubhmangalam19-collab
   ```
   *(GitHub will display a special message: "✨ You found a secret! `shubhmangalam19-collab/shubhmangalam19-collab` is a special repository that you can use to add a `README.md` to your GitHub profile.")*
3. Make sure it is set to **Public** 🌐.
4. Check **Add a README file** (or leave it unchecked if pushing with Git).
5. Click **Create repository**.

---

### Step 2: Add Your Polished Profile README
#### Method A: Directly in the GitHub Web Editor (Fastest - 30 seconds)
1. Go to your newly created repository: `https://github.com/shubhmangalam19-collab/shubhmangalam19-collab`
2. Click the pencil icon ✏️ to edit `README.md`.
3. Open [`README.md`](./README.md) in this folder, copy everything, and paste it into the editor.
4. Click **Commit changes...** (commit directly to `main`).

#### Method B: Push using Git CLI
Run these commands in PowerShell inside the `profile-readme` folder:
```powershell
cd "c:\Users\Shubh\Desktop\projects\github grind\profile-readme"
git init -b main
git add .
git commit -m "feat: launch epic github grind profile readme and workflows"
git remote add origin https://github.com/shubhmangalam19-collab/shubhmangalam19-collab.git
git push -u origin main
```

---

### Step 3: Enable the Contribution Snake Game (Optional but Awesome)
If you pushed the `.github/workflows/snake.yml` file:
1. Go to your repository `shubhmangalam19-collab/shubhmangalam19-collab` on GitHub.
2. Click on the **Actions** tab.
3. Click on the workflow **"Generate Contribution Snake Animation"** on the left menu.
4. Click **Run workflow** ➔ **Run workflow**.
5. Once it finishes (about 30 seconds), it will generate the animated snake eating your contribution dots automatically!

---

### Step 4: Add a Profile Avatar (Crucial for Credibility)
- Head over to **[github.com/settings/profile](https://github.com/settings/profile)**.
- Replace the default identicon with a high-res photo, a 3D avatar (e.g. from ReadyPlayerMe), or a stylized developer avatar (e.g. dicebear / midjourney).
- Add your bio: `Full-Stack Developer & Open Source Builder | On the #GitHubGrind 🚀`
- Set your location and links.
